# Open one page, then put a reminder on each phone

Open `household-chores.html` in a browser. It shows whose turn each chore is this week, moves the turn every Monday, and saves a calendar file for each person. The reminder goes on the calendar app already on that phone. There is nothing to install, subscribe to, or leave running.

The file is here: `/tmp/evals/v1/T07/household-chores.html`

Five chores cannot divide evenly by four people, so one person has two chores each week. That extra chore moves to the next person every Monday. Across four weeks, each person does each chore once.

## What is filled in, and what to change

These are stand-ins, edited on the page before anyone is sent a file:

- People, in rotation order: Alex, Bailey, Casey, Drew
- Chores, in rotation order: Kitchen, Bathrooms, Floors, Trash and recycling, Laundry
- First Monday of the rotation: 16 Nov 2026 (this week)
- Reminder: Monday at 8:00am

Person 1 has the extra chore on that first Monday. This week that is Alex: Kitchen and Laundry. Bailey has Bathrooms, Casey has Floors, and Drew has Trash and recycling. Next week the extra chore is Bailey's.

## Why this

The part a household of four actually needs is a shared answer to "whose turn is it?" and a nudge on each phone. The calendars already on those phones can do the nudge, and one saved page can do the rotation from the date, so nobody has to rebuild the chart on Sunday.

I checked the apps that advertise household chores. On [Tody's pricing page](https://todyapp.com/pricing), as of 20 Nov 2026, the free plan is one person. Syncing a plan across the house is Premium+ Family: $40 a year for up to six people. [Sweepy's US App Store listing](https://apps.apple.com/us/app/sweepy-home-cleaning-schedule/id1498897320) shows the paid plan at $3.99 a month or $19.99 a year. Either is a fair price later if you want people to tick chores off and keep a score. For a weekly rotation and a reminder, the page and the calendars are enough.

## Do this once

1. Open the file and replace the four names and five chores.
2. Tap **Save chart** and send `household-chores.html` to the household chat. Anyone can open it to see the current week. It works with no connection, and the names stay in the file.
3. Tap each person's reminder button and email that person their file. The event title names their chores. The note lists everyone's.
4. On an iPhone, add an iCloud calendar named Chores and turn on Event Alerts. Open the email in Mail and import the file into Chores. Apple's note on importing an .ics file from Mail is on the [iPhone calendar account page](https://support.apple.com/guide/iphone/set-up-mail-contacts-and-calendar-accounts-ipha0d932e96/ios).
5. On an Android phone, import on a computer. Google's help says the phone app does not import calendar files. Create a calendar named Chores, then use Settings, Import & export, and choose that calendar. Turn on notifications for it on the phone. Steps: [Import events to Google Calendar](https://support.google.com/calendar/answer/37118).
6. Open the first event and check that it says 8:00am. This Monday morning has already passed, so the first reminder is Monday 23 Nov 2026, for the week of 23–29 Nov. Until then, follow the list on the page.

The page also has **Copy this week**, for a one-off message in the household chat, and **Print a fridge sheet**.

If a phone will not take the file, set a repeating Monday 8:00am alarm named Chores and open the chart. The chart is the list that stays right.

## Watch out for

- The reminder files cover 104 weeks, through Monday 13 Nov 2028. The page keeps rotating after that. Save fresh files before they run out, and again whenever a name or chore changes. Delete the old Chores calendar before importing the new file, so the old reminders are not left beside the new ones.
- If someone is away, trade that one week between yourselves and leave the rotation as it is. The next Monday still moves on.
- After import, glance at the time on the first event. It should be 8:00am. If a calendar shows a different hour, delete that calendar and import the file again.

Checking a chore off, once it is done, stays with you. If that tick-off becomes the thing people actually need, Tody's Family plan is the one I would pay for.
