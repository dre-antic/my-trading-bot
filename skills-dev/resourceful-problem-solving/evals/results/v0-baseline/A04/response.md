Use `ls -a`.

```bash
ls -a
```

The `-a` flag includes hidden files and directories (names that start with `.`), plus the `.` and `..` entries.

A few related forms:

- `ls -la` — same listing, with permissions, owner, size, and timestamps
- `ls -A` — hidden files, but omit `.` and `..`
- `ls -a /path/to/dir` — list a directory other than the current one
