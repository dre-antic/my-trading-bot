`ls -a`

That lists every entry in the current directory, including hidden names that start with `.` (and the `.` and `..` entries).

Useful variants:

- `ls -la` — same listing, in long format (permissions, owner, size, date)
- `ls -A` — hidden files, but omit `.` and `..`
- `ls -a /path/to/dir` — a directory other than the one you are in
