# Aether Studio

**Topic in → publish-ready video out.**

Aether is an orchestrated multi-agent video production system. You describe a video. The Video Director researches the subject, writes a sourced script, gathers licensed or original visuals, narrates, captions, assembles an MP4, quality-checks it, and prepares a YouTube package. You approve. Nothing is published unless you say so.

It is built for a **2013 Intel MacBook Pro with 8 GB RAM** as the control machine: no local giant models, no Chromium renderer on the laptop, no surprise charges.

## Quick start

```bash
cp .env.example .env
npm install
npm test
npm run dev
```

Open http://localhost:5173 (UI) — the API listens on http://127.0.0.1:8787.

Demo mode is **on by default**. The full pipeline runs with mock/heuristic LLM, Wikipedia fallbacks when online, original graphics, eSpeak NG narration, bundled music, and FFmpeg. No API keys required.

Create a short documentary from the CLI:

```bash
npm run produce -- --topic "How Jamaican music influenced the world" --duration 25 --demo --offline
```

## What you get

1. Research package with citations and source tiers  
2. Fact-checked claims (`KNOWN` / `SUPPORTED` / `INFERRED` / `UNCERTAIN`)  
3. Concept → outline → script → scenes  
4. Stock search (Pexels, Pixabay, Wikimedia) with procedural graphics fallback  
5. Local TTS (eSpeak NG) with optional cloud/Kokoro adapters  
6. SRT + VTT captions (word-level timings)  
7. Ducking-ready music bed (original generated audio)  
8. FFmpeg render (16:9, 9:16, 1:1 · 720p/1080p)  
9. QC scores and an AI reviewer  
10. Titles, description, tags, chapters, thumbnail  
11. Job resume after shutdown  

Human work is limited to: choosing the brief, pasting optional API keys, approving paid spend, and approving the final video.

## Hardware policy

| Do | Do not |
|----|--------|
| Use the Mac as orchestrator, UI host, and light FFmpeg machine | Assume Apple Silicon or a modern GPU |
| Prefer free cloud APIs (Groq, Wikipedia, Pexels) | Download 7B+ local models onto 8 GB RAM |
| Default to 720p `veryfast` | Run Remotion/Chromium locally as the default renderer |

## Provider routing (free-first)

1. Local / open / original (FFmpeg, eSpeak, Wikipedia/Wikimedia APIs, generated graphics & music)  
2. Free public APIs  
3. Free cloud tiers (Groq, Gemini free, OpenRouter free, Cloudflare Workers AI)  
4. Cheapest paid, **only** if `ALLOW_PAID_PROVIDERS=true` and the Budget Manager authorizes it  
5. Better paid, only with explicit approval  

Default: `ALLOW_PAID_PROVIDERS=false`.

## Settings

The Settings page stores keys in `data/secrets.json` (gitignored). After save, the UI only shows a mask + last four characters. Keys are never sent to the browser in full and never written to logs.

## Tests

```bash
npm test
```

Includes unit tests (budget, cache, failover, captions, licenses, redaction) and an integration test that renders a real MP4 with `DEMO_MODE=true` and `OFFLINE_MODE=true`.
