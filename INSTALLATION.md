# Installation (Mac)

1. Copy `packaging/macos/JARVIS.app` after running `./scripts/build-jarvis-macos.sh` on the Mac, or copy this whole folder and run that script.
2. Drag **JARVIS** to **Applications**.
3. Right-click → **Open** the first time (unsigned build).
4. Optional: keep it in the Dock.

There is no Apple Developer signature on this build. That is honest, not a
claim of notarization.

Linux / development: `./scripts/launch-jarvis.sh`
