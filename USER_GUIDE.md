# User guide

Open **JARVIS** from the Dock (after the one-time install in INSTALLATION.md)
and type what you want.

- The window is this Mac, not the cloud.
- **Chat** is the main place to talk.
- **Missions** shows work in progress.
- **Permissions** is where you approve or reject sensitive steps.
- **Stop now** / **Pause safely** are always at the top.

If you want more detail, start with the README.
