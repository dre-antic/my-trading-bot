# User guide

This guide is for people who want to make videos, not for software engineers.

## Opening the studio

1. Open the **Applications** folder (or the Dock).
2. Click **AI Video Studio**.
3. A dark window appears. That is the studio.

If this is the first time, a short setup wizard checks your Mac and can run a tiny test video so you know everything works.

## Making a video

1. Click **New project**.
2. Type what you want, for example:
   - “Create a 60-second educational video explaining why the sky appears blue.”
3. Choose a platform (YouTube, Shorts, TikTok, both, or custom).
4. Choose a length, or leave **AI decides**.
5. Leave **Simple** unless you want extra choices.
6. Click **Create video**.

You can go do something else. The studio keeps working. If you quit and reopen, it continues from the last finished step.

## What the stages mean

| You see | What is happening |
|---|---|
| Research | Looking up the topic and saving sources |
| Script | Writing narration and scene notes |
| Storyboard | Breaking the script into shots |
| Visuals | Drawing or fetching licensed pictures and animating them |
| Voice | Reading the script aloud |
| Music | Creating original background music |
| Editing | Putting picture and sound on a timeline |
| Captions | Adding subtitles |
| Thumbnail | Designing a clickable image |
| Quality review | A second opinion, plus technical checks |
| Final render | Saving the MP4 you can play |

## Changing something

On the review screen, type a request such as:

- “Make the narrator sound more energetic.”
- “Shorten the introduction.”
- “Use cartoon visuals.”

Then click **Request changes**. The studio rebuilds only what that change needs.

## Downloading

Use:

- Download video
- Download thumbnail
- Download captions

The studio **never uploads** to YouTube or TikTok. You upload the files yourself.

## Personal vs commercial

Choose **Commercial** if the video is for a business or paid work. The studio then refuses models whose licenses are unknown, non-commercial, or unclear, unless you read the license screen and explicitly override.

## Money

Local production shows **$0 external cost**. If a cloud step might cost money, the studio stops and asks. It will not spend quietly. Set a max budget in Advanced if you later add paid providers.

## Voices and real people

You may create fictional characters. The studio will not clone a real person’s voice or face without authorization.

## If something looks wrong

Open **System status**. It explains, in plain English, things like:

“Video generation is using remote GPU because this Mac does not have enough graphics memory.”

You can also open **Tasks** to pause, resume, cancel, or retry a job.
