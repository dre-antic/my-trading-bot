# Optional Electron window

This folder is only a thin window around the local JARVIS app.

The real software lives in the `jarvis` Python package. You do not need Electron
on an 8 GB Intel Mac. Double-click **JARVIS.app** or run `scripts/launch-jarvis.sh`.

Electron is heavier than the Python window. Use it only if you already have it
and prefer that shell. It is not signed here.
